# Delta

Employee attendance backend — a Go implementation in `go/` with Firebase login, local JWT auth, outlet memberships, attendance/geofencing, salary reports, golang-migrate migrations, Prometheus metrics, and Docker support.

The Java sources under `src/main/java` remain in the repository as a read-only contract reference during the migration; they are never modified by this work.

See:

- `go/README.md` — quickstart, package map, ops endpoints, and links.
- `SETUP.md` for setup, configuration, ops endpoints, metrics/Grafana monitoring, and report usage.
- `STRUCTURE.md` for the Go package layout.
- `AGENTS.md` for coding-agent/project guidance.
